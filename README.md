# wave. React Native

This folder contains a TypeScript React Native port of the DMusic / wave. Flutter app.

## Run

1. Install dependencies with `npm install`.
2. Start the app with `npm run start`.
3. Open it in Expo Go, Android, iOS, or web from the Expo CLI.

## What is included

- Auth gate and profile sheet
- Bottom-tab shell with Home, Search, Prediction, Library, and Playlist Import
- Mini player and full player modal
- Shared theme, mock catalog, and backend-ready API service surface
